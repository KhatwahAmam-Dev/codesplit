# CodeSplit Studio - by Andrew Dwiranto
Dual-pane live code editor built with React

## Deploy to Vercel (2 cara)

Cara 1 - Drag & Drop (Paling Gampang):
1. Buka vercel.com
2. Login pakai GitHub
3. Klik Add New > Project > Deploy without Git
4. Drag folder ini atau file index.html
5. Jadi! Dapat link https://namamu.vercel.app

Cara 2 - Via GitHub:
1. Buat repo baru di github.com
2. Upload index.html ini
3. Di Vercel, Import Project dari GitHub repo tersebut
4. Klik Deploy

Fitur: PWA Installable, Python Pyodide, Live cdnjs search, Save System
